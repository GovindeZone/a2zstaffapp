# A to Z Employee Hub

Here's the updated prompt with your branding requirement added:

HR Attendance & Employee Management System

Create a simple HR Management application with a clean, modern, and mobile-friendly UI.

Application Branding

Display the company name prominently at the top of every page:

A to Z (large, bold, and stylish/fancy title)

Subtitle: OMR Road, Navalur Junction, Chennai (smaller text below the title)

Employee Management

Add, Edit, Delete Employee.

Employee Profile should include:

Full Name (Mandatory)

Phone Number (Mandatory)

Department (Mandatory)

Joining Date (Mandatory)

Relieving Date

Monthly Salary (Mandatory)

Bonus

Aadhaar Number (Mandatory)

Address (Mandatory)

Emergency Contact Name (Mandatory)

Emergency Contact Number (Mandatory)

Reference Name (Mandatory)

Reference Phone Number (Mandatory)

Allow uploading and updating employee documents:

Aadhaar

Resume

Other Documents (Memo, Warning Letter, Certificates, etc.)

Attendance

Provide daily attendance with the following options:

Present

Absent

Half Day (Morning Absent)

Half Day (Afternoon Absent)

Weekly Off

Salary Report

Generate salary reports:

By Period (From Date – To Date)

By Department

By Employee

All Employees

Salary should be automatically calculated based on the number of days worked during the selected period based on attendance records.

Include search, filters, and export options (Excel/PDF) for employee details and salary reports. The application should have a professional dashboard with simple navigation and responsive design.
